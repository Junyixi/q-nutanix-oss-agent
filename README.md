# AGI — Self-Evolving OSS Project Manager Agent

UCSB CMPSC 189A, Fall 2026 · Sponsored by Nutanix

## Project overview

AGI is developing an AI agent to help open-source maintainers triage issues, organize work, and investigate stalled pull requests. The agent is intended to improve through evaluated updates to its memory, tools, and workflows without retraining its base language model. Our proposed first milestone is an issue-triage prototype, with repository selection and success criteria to be agreed with our Nutanix mentors.

## Proposed first milestone

1. Select a target open-source repository with the mentors.
2. Establish a set of historical issues and maintainer-reviewed expected outcomes.
3. Build a review-only issue-triage baseline with evidence-linked recommendations.
4. Measure recommendation quality, unsupported claims, review effort, latency, and cost.
5. Evaluate versioned memory or workflow changes against that fixed baseline.

Later workflows, such as CI failure triage and specialized agents, depend on mentor feedback and measured value.
